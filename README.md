# CLOSE Browser

Адаптивный веб-интерфейс CLOSE Browser на HTML, CSS и JavaScript.

## Возможности

- Интерфейс на русском языке для компьютеров и телефонов.
- Вкладки, адресная строка и навигация назад/вперёд.
- Поиск через Google, Bing, DuckDuckGo или Brave.
- Просмотр сайтов внутри приложения через iframe, где сайт это разрешает.
- Быстрый доступ к сайтам, пользовательские ярлыки, локальные закладки и история.
- Тёмная и светлая темы.
- Настройки сохраняются локально через `localStorage`.

## Запуск

Открой `index.html` или опубликуй репозиторий через GitHub Pages (ветка `main`, папка `/ (root)`).

## Ограничения встроенного просмотра

CLOSE Browser — веб-приложение, а не отдельный браузерный движок. Некоторые сайты запрещают отображение во фрейме через `X-Frame-Options` или CSP `frame-ancestors`; такой запрет нельзя надёжно обойти из обычного HTML/JavaScript. Для полноценного браузера, который открывает любые сайты внутри собственного окна, нужен отдельный клиент на базе Chromium/WebView.
