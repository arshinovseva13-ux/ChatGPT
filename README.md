# Orbit Browser

Адаптивный веб-интерфейс Orbit Browser на HTML, CSS и JavaScript.

## Возможности

- Интерфейс на русском языке для компьютеров и телефонов.
- Вкладки, адресная строка и навигация назад/вперёд.
- Поиск через Google, Bing, DuckDuckGo или Brave.
- Встроенный просмотр сайтов во фрейме, если сайт это разрешает; для сайтов с запретом встраивания доступна кнопка открытия отдельно.
- Быстрый доступ к сайтам, пользовательские ярлыки, локальные закладки и история.
- Тёмная и светлая темы.
- Настройки сохраняются локально через `localStorage`.

## Запуск

Открой `index.html` или опубликуй репозиторий через GitHub Pages (ветка `main`, папка `/ (root)`).

## Ограничения встроенного просмотра

Orbit Browser — веб-приложение, а не отдельный браузерный движок. Оно не опубликовано в репозитории CloseApps: изменения сделаны только в репозитории ChatGPT. Некоторые сайты запрещают отображение во фрейме через `X-Frame-Options` или CSP `frame-ancestors`; такой запрет нельзя надёжно обойти из обычного HTML/JavaScript. Для полноценного браузера, который открывает любые сайты внутри собственного окна, нужен отдельный клиент на базе Chromium/WebView.

## Нативный браузер для Android

Папка [android](android/) содержит отдельное Android-приложение Orbit Browser на Kotlin и Android WebView. Оно предназначено для реального просмотра сайтов без ограничений iframe, которые есть у веб-демо GitHub Pages.

Сборка APK запускается GitHub Actions при изменениях в папке `android/`. После успешной сборки APK можно скачать из артефактов workflow **Build Orbit Browser APK** на вкладке Actions. Инструкции по локальной сборке: [android/README.md](android/README.md).
