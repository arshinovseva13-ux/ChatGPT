# CLOSE Browser

Адаптивный браузерный веб-интерфейс CLOSE Browser на HTML, CSS и JavaScript.

## Возможности

- Интерфейс на русском языке, адаптивный для телефона и компьютера.
- Вкладки, адресная строка и переход назад/вперёд по истории вкладки.
- Поиск через Google, Bing, DuckDuckGo или Brave.
- Быстрый доступ к сайтам и возможность добавлять собственные ярлыки.
- Локальные закладки и история просмотров.
- Тёмная и светлая темы.
- Локальное хранение настроек через `localStorage`.

## Запуск

Открой `index.html` в браузере или включи GitHub Pages в настройках репозитория, выбрав ветку `main` и папку `/ (root)`.

## Важно

Это веб-приложение с интерфейсом браузера, а не отдельный браузерный движок. Из-за ограничений безопасности браузеров и политики сайтов страницы открываются в новой вкладке; произвольные сайты нельзя надёжно встраивать внутрь этого приложения. Полноценный браузер с движком Chromium требует отдельного приложения или оболочки на базе браузерного движка.
