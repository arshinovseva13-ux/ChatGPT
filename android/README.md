# Orbit Browser для Android

Нативная версия Orbit Browser на Kotlin и Android WebView. В отличие от веб-демо на GitHub Pages, она использует системный браузерный движок Android и не ограничена политикой встраивания iframe.

## Возможности
- Настоящий Android WebView для сайтов без iframe.
- Поиск DuckDuckGo по умолчанию, выбор Google, Bing и Brave.
- Автоматическое распознавание адресов и поисковых запросов.
- Вкладки, назад/вперёд, обновление и домашняя страница.
- Локальные закладки и история.
- Режим отображения сайтов как на компьютере.
- Сохранение поисковой системы и последнего URL на устройстве.

## Сборка APK
Открой папку `android` в Android Studio с JDK 17 и Android SDK Platform 35. Затем выбери **Build → Build APK(s)**. Результат появится в `android/app/build/outputs/apk/debug/app-debug.apk`.

Это исходный проект; APK ещё нужно собрать и проверить на устройстве.
